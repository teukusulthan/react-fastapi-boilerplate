## PROJECT SCOPE
Project scope defines the boundaries and goals of the application being built.

### Proof-of-Concept (POC)
- A web or mobile application that uses mock data
- Mock data must be created and stored within the web or mobile project itself — no separate backend project
- Follow the mock data creation rules and conventions defined in each project's guidelines
- **Always ask the user before writing any backend code in POC scope**

### MVP (Minimum Viable Product)
- A web or mobile application connected to a backend
- Use **real database** if the data is complete and validated; use **mock data** if the data is incomplete or not yet validated
- Check the project's rules and conventions before writing any backend code

### Production
- A web or mobile application connected to a backend using real data — either from a database or an external source
- **Mock data is not allowed** in production scope
- **All data must be validated** before being used or connected to the application
- Check the project's rules and conventions before writing any backend code
